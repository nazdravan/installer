Как с ним работать

Флешку готовите один раз, дома. В классе каждому компьютеру — один щелчок.

Дома распакуйте архив на флешку. Рядом с программой лежит папка Windows (или Linux), в ней по папке на каждую программу: её установщик и короткий файл program.toml — какая это версия и как её поставить без окон.

E:\
Instalator.exe
Windows\
Furnica\ program.toml, furnica-3.0.5-windows7-x86-portable.zip
Cangurul\ program.toml, cangurul-3.0.6-windows7-x86-portable.zip
Audacity\ program.toml, audacity-win-3.6.4-64bit.exe
jurnal\

В классе запустите Instalator.exe, Windows один раз спросит права администратора. На Linux наберите в терминале sh /media/…/instalator.sh и один раз введите пароль. Буква флешки не важна.

На экране видно, чего не хватает и что устарело. Программа читает установленную версию (из реестра в Windows, из dpkg в Linux) и сравнивает с версией на флешке: отсутствующие и устаревшие уже отмечены, актуальные — нет.

Администраторам

Что происходит на компьютере, когда вы нажимаете «Instalează». Выберите гарантию или поищите.

  • Ничего из интернетаВсё берётся с флешки: установщики, описания, даже запасной OpenGL для компьютеров без видеодрайвера. Сеть не используется вовсе.
  • Без окон и без «Далее»msiexec запускается с /qn /norestart, установщики .exe — с тихими ключами из program.toml, apt-get — с -y. Компьютер сам не перезагружается.
  • Зависания прерываютсяЕсли установщик всё-таки ждёт щелчка, через 30 минут он останавливается вместе с запущенными им процессами, и очередь идёт дальше.
  • Одна ошибка не мешает остальнымУ каждой программы свой результат, ошибка — с причиной (код выхода, сообщение apt); остальные продолжают ставиться.
  • Только недостающее и устаревшееУстановленная версия читается из реестра (оба представления на 64 битах), из dpkg или из метки установщика и сравнивается с версией на флешке.
  • Чужие установки не трогаютсяЕсли программа попала в ту же папку иначе (например, из .msi), установщик её не трогает и просит сначала удалить.
  • Журнал для каждого компьютераНа флешке остаётся jurnal\ИМЯКОМПЬЮТЕРА-дата-время.txt с системой, выполненными командами и результатом каждой. На защищённой от записи флешке установка идёт без журнала.
  • Открытый кодНаписана на Rust, лицензия GPL-3.0. Код, описания и сборки открыты на GitHub, с контрольными суммами SHA256 для каждого архива.

Ничего не найдено. Попробуйте «журнал», «интернет» или «версия».
